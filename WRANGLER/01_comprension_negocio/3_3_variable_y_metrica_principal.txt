================================================================================
3.3  VARIABLE A OPTIMIZAR Y METRICA PRINCIPAL DEL PROYECTO
     Proyecto: Sistema de recomendacion de peliculas por filtrado colaborativo
     Dataset:  MovieLens ml-latest-small (100.836 calificaciones, 610 usuarios,
               9.724 peliculas calificadas)
================================================================================


A) LA VARIABLE A OPTIMIZAR
--------------------------------------------------------------------------------

  VARIABLE:   rating  r(u,i)
  QUE ES:     la calificacion, en estrellas, que el usuario u daria a la
              pelicula i para la que aun no hay una nota observada.
  TIPO:       numerica continua en la prediccion, r(u,i) pertenece a [0,5, 5]
              (los datos observados avanzan en medias estrellas; el modelo
               puede devolver un valor continuo, por ejemplo 4,23).
  SENTIDO DE
  LA OPTIMIZACION:  se MINIMIZA el error entre lo predicho y lo real.
                    No se maximiza el rating: predecir "5 a todo el mundo"
                    no personaliza y puede equivocarse mucho.

  Cuantas veces hay que estimarla (matriz de peliculas calificadas):
      Celdas de la matriz 610 x 9.724 ........... 5.931.640
      Observadas (ya conocidas) ................. 100.836 ( 1,70%)
      Sin nota observada ........................ 5.830.804 (98,30%)

  Por que esta y no otra:
      - Es la variable que expresa PREFERENCIA en ratings.csv. El genero y
        el anio de estreno describen peliculas; no son la nota a predecir.
      - Es numerica y conserva el orden: un 5 no es lo mismo que un 4.
      - Con las predicciones se construye el ranking personalizado Top-N.


B) LA METRICA PRINCIPAL: RMSE
--------------------------------------------------------------------------------

  NOMBRE:   RMSE (Root Mean Squared Error / Raiz del Error Cuadratico Medio)

  FORMULA:

                        ______________________________
                       /      1
        RMSE   =      /   -------  *  SUMA  ( r(u,i) - r_pred(u,i) )^2
                    \/     |T|        (u,i) en T

        donde:
          T            = pares usuario-pelicula reservados para prueba.
                         |T| = 20.168 calificaciones (20%).
          r(u,i)       = calificacion REAL que dio el usuario (0,5 a 5).
          r_pred(u,i)  = calificacion PREDICHA por el modelo.

  COMO SE CALCULA, PASO A PASO:
      1. Se reparten 100.836 calificaciones: 80.668 para entrenamiento y
         20.168 para prueba (baselines.json).
      2. El modelo se entrena solo con entrenamiento.
      3. Para cada par del test se predice r_pred(u,i).
      4. Se resta la nota real menos la predicha.
      5. Se eleva al cuadrado cada error.
      6. Se promedian esos cuadrados y se extrae la raiz.

  COMO SE LEE EL RESULTADO:
      El RMSE esta en estrellas. El valor medido del modelo es 0,8478.
      Es la raiz del error cuadratico medio, no la desviacion absoluta
      promedio: para eso se usa el MAE (0,6482).

  POR QUE RMSE Y NO OTRA:
      - Es una metrica de regresion, coherente con la tarea marcada en 3.2.
      - Penaliza mas los errores grandes: confundir un 5 con un 2 (error 3)
        aporta nueve veces mas error cuadratico que confundir un 5 con un 4.
      - Se expresa en la misma unidad que el rating.


C) METRICAS SECUNDARIAS (apoyo, no principal)
--------------------------------------------------------------------------------

  MAE (Error Absoluto Medio)

                   1
        MAE  =  -------  *  SUMA  | r(u,i) - r_pred(u,i) |
                  |T|      (u,i) en T

        Mide la desviacion absoluta promedio. El modelo obtiene 0,6482 en
        prueba (mf_numpy.json).

  COBERTURA DE CATALOGO
        Porcentaje de peliculas distintas que aparecen en algun Top-10
        recomendado, sobre las 9.742 del catalogo. Aun no esta medido.

  PRECISION@10
        De las 10 peliculas recomendadas por usuario, fraccion con nota
        observada >= 4 en la prueba. La evaluacion disponible usa 389
        usuarios: 68,15% para el modelo frente a 64,68% para el ranking
        por media de pelicula (antes_despues.json).

      REGLA DE DESCARTE: superar el RMSE 0,868 de media + sesgos.

G) COMO SABEMOS QUE YA ESTA OPTIMIZADO
--------------------------------------------------------------------------------

  "Optimizado" se defiende con comparaciones sobre la misma prueba, un
  umbral previo, validacion separada y ausencia de fuga de datos. No equivale
  a RMSE = 0 ni demuestra un minimo global de todos los hiperparametros.

  PRUEBA 1 - ESCALERA DE BASELINES
  ..............................................................................
      Media global .................... 1,0368
      Media por usuario .............. 0,9367
      Media por pelicula ............. 0,9730
      Media + sesgos (mu+bu+bi) ...... 0,8677
      Factorizacion matricial ........ 0,8478
      El modelo reduce el RMSE un 12,9% frente a media por pelicula y
      un 2,3% frente a media + sesgos.

  PRUEBA 2 - UMBRAL
  ..............................................................................
      RMSE <= 0,90 y MAE <= 0,70. El modelo cumple ambos en test.

  PRUEBA 3 - VALIDACION DE HIPERPARAMETROS
  ..............................................................................
      La ejecucion de mf_numpy.json registra 64 factores y la mejor epoca
      de validacion 28 (RMSE de validacion 0,8578). El historial de epocas
      permite observar la parada; falta documentar un barrido amplio de K,
      tasa de aprendizaje y regularizacion antes de afirmar un optimo global.

  PRUEBA 4 - VALIDACION CRUZADA
  ..............................................................................
      Pendiente: repetir con varias particiones y reportar media y dispersion.

  PRUEBA 5 - AUSENCIA DE FUGA DE DATOS
  ..............................................................................
      Las medias y sesgos de los baselines se calculan con entrenamiento.
      La epoca se elige en validacion y el test se reserva para evaluacion.

  COMPROBACION ADICIONAL DE NEGOCIO
  ..............................................................................
      Cobertura de catalogo del Top-10 (cuaderno H3): 3,2% (315 de 9.724);
      no alcanza la meta de 22,9% (CN-3).
      Precision@10 en 389 usuarios: 68,15% modelo y 64,68% media de pelicula.


COMO SE DEFIENDE EN LA EXPOSICION

  "El modelo de 64 factores obtuvo RMSE 0,8478 y MAE 0,6482 en prueba.
   Reduce el RMSE un 12,9% frente al ranking por media de pelicula y un
   2,3% frente al baseline de sesgos. La mejor epoca de validacion fue 28.
