Antes de las fórmulas: el montaje

Todos los escalones se miden exactamente igual. Si el montaje cambia entre modelos, la comparación no vale nada.

Reglas del experimento

  • Partición 80 / 20: 80.668 calificaciones para estimar, 20.168 reservadas para medir.
  • El test no se toca jamás. Todas las medias y sesgos se calculan solo con entrenamiento. Calcular la media de un usuario incluyendo notas del test es fuga de datos, e infla el resultado.
  • Semilla fija (42). Sin ella los números no se reproducen y no se pueden defender.
  • Recorte a [0,5, 5]. Las fórmulas pueden devolver valores fuera de la escala observada. Se recorta antes de medir el error.
  • Caso desconocido → se cae a μ. Si en el test aparece una película sin votos en entrenamiento, se predice la media global. Nunca se descarta la fila: eso sería medir solo lo fácil.

Los cuatro escalones

Cada referencia usa una señal distinta. En estos datos, la media por usuario tiene menor RMSE que la media por película; la combinación de sesgos mejora ambas.

1

Media global

El suelo

Predice el mismo número para todo el mundo y para toda película: la media de todas las calificaciones del entrenamiento. No mira quién eres ni qué película es.

Información que usa: ninguna. Es la referencia mínima: todo modelo candidato debe superarla.

μ = 1|R|  ∑(u,i) ∈ R r(u,i) = 3,4999
r̂(u,i) = μ para todo par (u, i)
R = calificaciones de entrenamiento |R| = 80.668 r̂ = valor predicho
RMSE1,0368
MAE 0,8213
2

Media por usuario

Quién califica

A cada usuario se le predice su propia media histórica. Reconoce que hay gente exigente y gente generosa, pero le da la misma nota a todas las películas.

Añade: el nivel de exigencia del usuario. Baja el error un 9,7 %; o sea, saber quién puntúa vale bastante.

r̂(u,i) = μu = 1|Iu|  ∑i ∈ Iu r(u,i)
Iu = películas que u calificó en entrenamiento 610 medias, una por usuario usuario sin historial → μ
RMSE0,9367
MAE 0,7287
3

Media por película

Ranking de referencia

A cada película se le predice su nota media. Es, literalmente, recomendar por popularidad: el mismo ranking para los 610 usuarios. Este es el ranking de referencia.

Añade: la calidad de la película. En esta prueba, su RMSE es mayor que el de la media por usuario.

r̂(u,i) = μi = 1|Ui|  ∑u ∈ Ui r(u,i)
Ui = usuarios que calificaron i en entrenamiento 9.022 medias de películas presentes en entrenamiento película sin votos → μ
RMSE0,9730
MAE 0,7520
4

Media + sesgos

El listón real

Junta las dos cosas anteriores, pero sin sumarlas ingenuamente. Primero calcula cuánto se desvía cada película de la media global; después, sobre lo que queda sin explicar, cuánto se desvía cada usuario. El orden de cálculo importa.

Añade: las dos señales a la vez, sin contarlas dos veces. Es el baseline combinado de este experimento y, por tanto, el listón que el filtrado colaborativo tiene que superar para justificarse.

PASO 1 — SESGO DE LA PELÍCULA
bi = ∑u ∈ Ui ( r(u,i) − μ ) λ + |Ui|
PASO 2 — SESGO DEL USUARIO, SOBRE EL RESIDUO
bu = ∑i ∈ Iu ( r(u,i) − μ − bi ) λ + |Iu|
PASO 3 — PREDICCIÓN
r̂(u,i) = μ + bu + bi
λ = 2  (regularización) bi = cuánto sube o baja esa película bu = cuánto sube o baja ese usuario

Qué pinta ahí la λ

Sin λ, una película con un solo voto de 5★ recibe el sesgo máximo y el modelo se fía ciegamente de ella. Al sumar λ al denominador, los sesgos calculados con pocos datos se encogen hacia cero: el modelo desconfía de lo que ha visto poco. Con 9.274 películas calificadas por debajo de 50 votos, aquí eso no es un detalle.

RMSE0,8677
MAE 0,6647

Factorización matricial — el modelo entrenado

Medido

Añade factores a los sesgos: descompone la matriz en 64 factores latentes y aprende gustos, no niveles. Es el escalón que justifica el proyecto. Implementado en numpy (03b_mf_numpy.py); el número de factores y la época de parada se eligen con una validación, y el test se mide una sola vez.

RMSE0,8478
MAE 0,6482 · −12,9 % en RMSE frente a media por película

Cómo leer la comparación

Cada escalón se mide en las mismas 20.168 notas reservadas para prueba. El modelo de factores añade una señal que el baseline de sesgos no captura.

El listón medido con estos datos

La media más sesgos obtiene RMSE 0,8677 en prueba; la factorización matricial obtiene 0,8478.

Regla de descarte

El modelo de factores reduce el RMSE un 2,3 % frente a los sesgos. Los valores salen de baselines.json y mf_numpy.json, generados con ml-latest-small.

Con qué se miden

Las dos métricas se calculan sobre el mismo conjunto de prueba, después de recortar las predicciones a [0,5, 5].

RMSE = √ 1|T| ∑(u,i) ∈ T ( r(u,i) − r̂(u,i) )² castiga los errores grandes
MAE = 1|T| ∑(u,i) ∈ T | r(u,i) − r̂(u,i) | error medio, sin castigo extra
T = conjunto de prueba, |T| = 20.168 ambas se leen en estrellas la decisión se toma con RMSE

Por qué el RMSE manda: elevar al cuadrado hace que confundir un 5 con un 2 pese nueve veces más que confundir un 5 con un 4. En un recomendador eso es lo correcto — el fallo grave no es afinar mal, es poner delante algo que la persona va a detestar.

Cómo se defiende

«Fijamos el umbral RMSE ≤ 0,90 antes de modelar. Construimos cuatro modelos de referencia sobre la misma partición 80/20, con semilla fija y sin tocar el conjunto de prueba. La media global da 1,0368; recomendar por popularidad, que es el ranking de referencia, da 0,9730; y el mejor modelo sin personalizar :media más sesgos de usuario y de película: da 0,8677.

Ese 0,8677 es nuestro criterio de descarte: si el filtrado colaborativo no baja de ahí, no aporta nada sobre dos medias bien calculadas y no se justifica ponerlo en producción.»
