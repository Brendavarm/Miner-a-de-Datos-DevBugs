Antes de las fórmulas: el montaje

Todos los escalones se miden exactamente igual. Si el montaje cambia entre modelos, la comparación no vale nada.

Reglas del experimento

  • Partición 80 / 20 — 800.167 calificaciones para estimar, 200.042 reservadas para medir.
  • El test no se toca jamás. Todas las medias y sesgos se calculan solo con entrenamiento. Calcular la media de un usuario incluyendo notas del test es fuga de datos, e infla el resultado.
  • Semilla fija (42). Sin ella los números no se reproducen y no se pueden defender.
  • Recorte a [1, 5]. Las fórmulas pueden devolver 5,4 o 0,7; un rating no puede. Se recorta antes de medir el error.
  • Caso desconocido → se cae a μ. Si en el test aparece una película sin votos en entrenamiento, se predice la media global. Nunca se descarta la fila: eso sería medir solo lo fácil.

Los cuatro escalones

El orden no es decorativo: cada peldaño añade exactamente un tipo de información, y la bajada del error dice cuánto valía esa información.

1

Media global

El suelo

Predice el mismo número para todo el mundo y para toda película: la media de todas las calificaciones del entrenamiento. No mira quién eres ni qué película es.

Información que usa: ninguna. Es la referencia mínima — cualquier modelo que no la supere está roto.

μ = 1|R|  ∑(u,i) ∈ R r(u,i) = 3,5821
r̂(u,i) = μ para todo par (u, i)
R = calificaciones de entrenamiento |R| = 800.167 r̂ = valor predicho
RMSE1,1167
MAE 0,9328
2

Media por usuario

Quién califica

A cada usuario se le predice su propia media histórica. Reconoce que hay gente exigente y gente generosa, pero le da la misma nota a todas las películas.

Añade: el nivel de exigencia del usuario. Baja el error un 7,4 % — o sea, saber quién puntúa vale bastante.

r̂(u,i) = μu = 1|Iu|  ∑i ∈ Iu r(u,i)
Iu = películas que u calificó en entrenamiento 6.040 medias, una por usuario usuario sin historial → μ
RMSE1,0344
MAE 0,8273
3

Media por película

La práctica actual

A cada película se le predice su nota media. Es, literalmente, recomendar por popularidad: el mismo ranking para los 6.040 usuarios. Este es el rival a batir, porque es lo que la plataforma hace hoy.

Añade: la calidad de la película. Y resulta que importa más que el usuario — saber qué se puntúa vale más que saber quién puntúa.

r̂(u,i) = μi = 1|Ui|  ∑u ∈ Ui r(u,i)
Ui = usuarios que calificaron i en entrenamiento 3.669 medias, una por película película sin votos → μ
RMSE0,9765
MAE 0,7800
4

Media + sesgos

El listón real

Junta las dos cosas anteriores, pero sin sumarlas ingenuamente. Primero calcula cuánto se desvía cada película de la media global; después, sobre lo que queda sin explicar, cuánto se desvía cada usuario. El orden importa.

Añade: las dos señales a la vez, sin contarlas dos veces. Es el modelo más fuerte que existe sin personalizar de verdad — y por tanto el listón que el filtrado colaborativo tiene que superar para justificarse.

PASO 1 — SESGO DE LA PELÍCULA
bi = ∑u ∈ Ui ( r(u,i) − μ ) λ + |Ui|
PASO 2 — SESGO DEL USUARIO, SOBRE EL RESIDUO
bu = ∑i ∈ Iu ( r(u,i) − μ − bi ) λ + |Iu|
PASO 3 — PREDICCIÓN
r̂(u,i) = μ + bu + bi
λ = 2  (regularización) bi = cuánto sube o baja esa película bu = cuánto sube o baja ese usuario

Qué pinta ahí la λ

Sin λ, una película con un solo voto de 5★ recibe el sesgo máximo y el modelo se fía ciegamente de ella. Al sumar λ al denominador, los sesgos calculados con pocos datos se encogen hacia cero: el modelo desconfía de lo que ha visto poco. Con 1.192 películas por debajo de 50 votos, aquí eso no es un detalle.

Lo que revela este caso

El usuario 1150 es muy exigente: su media es 2,61 frente al 3,58 global. Forrest Gump es muy querida: 4,12 de media. Recomendar por popularidad le predice 4,12 y él le puso 1 — un error de más de 3 estrellas, peor que no personalizar nada.

Aquí el escalón 4 tampoco acierta (3,16), y esa es justamente la lección: sumar medias no basta. Sabe que este usuario es duro y que esta película gusta, pero no sabe que a él este tipo de película no le va. Eso — el gusto, no el nivel — es lo único que el filtrado colaborativo aporta, y es la razón de ser del proyecto.

Un hallazgo que cambia el listón

Al reproducir el escalón 4 apareció una diferencia con el valor documentado en el objetivo del proyecto.

El baseline de sesgos no es 0,930 — es 0,905

El documento de comprensión del negocio fija RMSE 0,930 para μ+bu+bi. Ese número sale de calcular los dos sesgos por separado, cada uno como desviación de la media global:

bu = μu − μ   y   bi = μi − μ→ RMSE 0,9315

Eso cuenta dos veces parte de la misma desviación. La formulación estándar calcula bi primero y bu sobre el residuo que queda, y da 0,9057; con λ=2, 0,9051.

Consecuencia práctica: la regla de descarte del proyecto («si no bajas de 0,930, el filtrado colaborativo no aporta») está puesta demasiado baja. El listón honesto es 0,9051. El SVD sigue superándolo, pero el margen real cae del 6,1 % al 3,5 % — y ese es el número que hay que defender, no el otro.

Con qué se miden

Las dos métricas se calculan sobre el mismo conjunto de prueba, después de recortar las predicciones a [1, 5].

RMSE = √ 1|T| ∑(u,i) ∈ T ( r(u,i) − r̂(u,i) )² castiga los errores grandes
MAE = 1|T| ∑(u,i) ∈ T | r(u,i) − r̂(u,i) | error medio, sin castigo extra
T = conjunto de prueba, |T| = 200.042 ambas se leen en estrellas la decisión se toma con RMSE

Por qué el RMSE manda: elevar al cuadrado hace que confundir un 5 con un 2 pese nueve veces más que confundir un 5 con un 4. En un recomendador eso es lo correcto — el fallo grave no es afinar mal, es poner delante algo que la persona va a detestar.

Cómo se defiende

«Fijamos el umbral RMSE ≤ 0,90 antes de modelar. Construimos cuatro modelos de referencia sobre la misma partición 80/20, con semilla fija y sin tocar el conjunto de prueba. La media global da 1,1167; recomendar por popularidad, que es la práctica actual, da 0,9765; y el mejor modelo sin personalizar —media más sesgos de usuario y de película— da 0,9051.

Ese 0,9051 es nuestro criterio de descarte: si el filtrado colaborativo no baja de ahí, no aporta nada sobre dos medias bien calculadas y no se justifica ponerlo en producción.»
